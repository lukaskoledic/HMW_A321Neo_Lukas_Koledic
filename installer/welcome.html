HMW A321neo for X-Plane 12

This package installs the HMW A321neo Installer application. The application downloads the aircraft directly from the HoldMyWire GitHub repository, so the installation always reflects the most recent commit on the main branch.

What happens next

  • The installer app is placed in your /Applications folder.
  • Launch it and confirm the X-Plane 12 location if it is not detected automatically.
  • The aircraft is fetched from GitHub and written to X-Plane 12/Aircraft/HMW_A321Neo_AppleSilicon_Dev.
  • Start X-Plane 12 and select the HMW A321neo from the aircraft list.

Updating

Re-run the installer at any time. It will pull the newest main commit and replace the installed aircraft, while preserving your liveries, display preferences and saved EFB configuration.

Requirements

  • X-Plane 12 for macOS
  • Git command line tools (git must be available)
  • An internet connection for the GitHub download
