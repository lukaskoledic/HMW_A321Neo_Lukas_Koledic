# Legacy texture template

This folder only documents the active legacy texture layout. It intentionally contains no painted PNGs, so it will not override the aircraft by itself.

To create a real starter livery with copies of the supplied 4096x4096 legacy maps, run from the aircraft package root:

    zsh tools/prepare_legacy_livery.command "My Legacy Livery"

Paint the generated PNGs while preserving their dimensions, UV layout, exact case, and filenames. Keep the supplied blue cockpit textures unchanged.
