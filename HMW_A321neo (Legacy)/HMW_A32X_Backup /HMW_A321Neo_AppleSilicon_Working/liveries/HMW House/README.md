# HMW House -- plain-white legacy livery

This folder is already in X-Plane livery format. Copy the entire `HMW House` folder into the aircraft's `liveries/` directory:

`HMW_A321Neo_AppleSilicon_Test/liveries/HMW House/`

The white texture maps are under `objects/legacy/texture/`. They preserve dark aircraft details, windows, openings, and gear hardware while removing the supplied Airbus branding and blue paint. The original paint-kit starter maps remain one level above this livery folder for reference.

To create the final house livery, edit the PNGs in this folder and keep their exact names, 4096 x 4096 dimensions, PNG format, and legacy UV layout. The blue cockpit textures are not overridden by this livery and remain preserved in the aircraft package.

Normal maps are intentionally omitted so the aircraft's working legacy normal maps continue to be used.
